
# 🎬 VisionCaption AI — AMD AI Hackathon 2026

### 🌐 Live Demo
----------------------------------

**VisionCaption AI** is an AI-powered video captioning platform developed by **Team Code Smashers** for the **AMD AI Hackathon 2026** (Track 2 – *Video Captioning*).

The platform automatically analyzes **30-second to 2-minute videos** and generates **four unique styles of captions**:

- 📝 Formal
- 😏 Sarcastic
- 🤖 Humorous-Tech
- 😂 Humorous (Non-Tech)

Unlike conventional caption generators, VisionCaption AI combines **Machine Learning**, **Large Language Models**, and **Computer Vision** to understand the context, actions, emotions, and objects in a video before producing highly accurate captions tailored to different audiences.

Powered by **AMD Cloud** and **Fireworks AI APIs**, the platform delivers fast inference, intelligent caption generation, and an engaging user experience.

# 💡 Our Solution

To solve this challenge, our team developed **VisionCaption AI**, an intelligent AI-powered platform capable of understanding videos and generating multiple caption styles with high contextual accuracy.

Instead of producing a single generic caption, VisionCaption AI understands the entire video and creates four distinct versions of captions, allowing creators, educators, businesses, and developers to choose the tone that best fits their audience.

The platform combines modern AI technologies with machine learning models that continuously improve caption quality through intelligent learning and optimization.

# 🚀 Getting Started

## Prerequisites

- Python 3.10+
- Node.js
- npm
- Fireworks AI API Key

---

## Installation

### Clone Repository

```bash
git clone https://github.com/MDAmanMonazir/VisionCaption-AI.git
```

---

### Navigate to Project

```bash
cd VisionCaption-AI
```

---

### Install Backend Dependencies

```bash
pip install -r requirements.txt
```

---

### Install Frontend Dependencies

```bash
cd frontend

npm install
```

---

### Configure Environment Variables

Create a `.env` file.

```env
DATABASE_URL=

SECRET_KEY=

ALGORITHM=HS256

ACCESS_TOKEN_EXPIRE_MINUTES=30

FIREWORKS_API_KEY=

SMTP_HOST=

SMTP_PORT=

SMTP_USER=

SMTP_PASS=

SMTP_FROM=

RESEND_API_KEY=
```

---

### Start Backend

```bash
uvicorn app.main:app --reload
```

---

### Start Frontend

```bash
npm run dev
```
